What the hell is this?

BonziBOX is a node.js socket.io chat client that you can chat with friends or mess up!

This server is completey vibecoded shit. It's half-vibecoded half-written.

It's not a good server, but it's a fun one.

Background gradient made by me with background-image: linear-gradient(to left, #6a4bad, #9168e8), url('your-image.jpg'); btw.

How do i use it?

  • Enter a name (under 32 characters)
  • Optionally, enter a profile picture URL. The simplest ones:
    • catbox.moe
    • File Garden
    • Imgur

What are the chat commands?

  • /hello [GUID] - Greet someone.
  • /name [NAME] - Change your name.
  • /img [URL] - Send an image URL. See up for the URLS.
  • /me [ACTION] - Do an action.
  • /clear - Clear your chat.
  • /admin [PASSWORD] - Admin mode.
  • /asshole [GUID] - Call someone an asshole.

    • Admin commands

    • /kick [GUID] - Kick someone.
    • /ban [GUID] [MINUTES] - Ban someone.
    • /forcemessage [GUID] [TEXT] - Force someone to say something.
